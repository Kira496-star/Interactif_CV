# Interactif_CV
The goal  is to design, develop, and deploy a cutting-edge, ultra-modern personal portfolio and interactive CV website. Moving beyond a static PDF resume, this digital platform showcases technical excellence

#Technology Stack Selection

1. Core Frontend Technologies
2. 
HTML5: Semantic, clean document structure ensuring proper accessibility and SEO optimization for search crawlers and recruiter tooling.
Tailwind CSS (via CDN): Utility-first styling framework utilized for rapid layout development, responsive design modifiers, and custom glassmorphism token implementation without complex local build pipelines.
Vanilla JavaScript (ES6+): Lightweight, dependency-free script handling UI state transformations (skills filtering, project modal open/close states, mobile menu toggling, and contact form feedback).

3. Design Assets & Styling Enhancements
4. 
Custom CSS Variables / Glassmorphism Tokens: Tailored styling for background radial gradients, frosted glass panels (backdrop-filter), and smooth transition easing functions.
Lucide Icons: Modern, clean SVG vector icons integrated for professional visual representation across experience timelines, skills categories, and interactive buttons.

5. Deployment & Infrastructure
GitHub Version Control: Modular repository architecture (index.html, css/style.css, js/main.js) managed via professional Kanban workflows.
